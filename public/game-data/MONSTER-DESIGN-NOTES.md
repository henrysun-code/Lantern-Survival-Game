# 怪物設計討論紀錄

## 核心方向

怪物盡量和日常生活中的事物有關，讓玩家一看就理解危險來源。

目前提燈遊戲的主題方向是：

> 夏夜、停電、害蟲、提燈、防蚊

## 怪物構想

| 怪物 | 生活來源 | 預計行為 |
|---|---|---|
| 蚊子 | 夏天常見害蟲 | 接近玩家後加速衝刺，碰撞造成傷害，之後逃離 |
| 飛蛾 | 被燈光吸引 | 靠近提燈，數量多但血量低 |
| 蒼蠅 | 食物或垃圾附近 | 高速、不規則移動 |
| 蟑螂 | 房間、廚房 | 速度慢、血量高 |
| 螞蟻 | 食物周圍 | 成群出現，單隻很弱 |
| 蜘蛛 | 房間角落 | 移動慢，但接觸傷害高 |
| 太陽 | 夏日曝曬 | 靠近時少量回血，但增加曬黑值；曬太久會造成持續傷害 |

## 蚊子特殊行為

預計狀態流程：

```text
approach → charge → hit → retreat → cooldown
```

行為規則：

1. 平常慢慢接近玩家。
2. 玩家進入指定範圍後，蚊子加速並固定方向衝刺。
3. 沒有撞到玩家時，持續往原方向衝，直到和玩家距離太遠，再回到追蹤。
4. 只有真正撞到玩家並造成傷害，才啟動「蚊蟲叮咬」並往反方向逃離。
5. 逃離結束後冷卻，再次接近玩家。

可能的資料欄位：

```text
behavior: dashRetreat
speed
dashSpeed
triggerRange
dashDuration
retreatSpeed
retreatDuration
contactDamage
statusEffect
statusDamagePerSecond
statusDuration
```

## 太陽特殊行為

太陽不是單純敵人，而是「有利但有代價」的特殊怪物：

- 靠近太陽：玩家少量回血。
- 同時累積曬黑值。
- 曬黑值高時，玩家外觀變暗。
- 超過門檻後開始受到持續傷害。
- 更高階段可以降低移動速度或其他能力。

建議階段：

```text
0–39：只有外觀變深
40–69：少量持續傷害
70–100：持續傷害增加，可能降低移動速度
```

## 目前程式支援狀態

目前已加入 `mosquito` 蚊子範例，使用 `dashRetreat` 共用行為與 `mosquitoBite` 持續扣血狀態；外觀暫時使用粉紅三角形 Placeholder。

目前怪物設定已能通用調整：

- 血量、速度、傷害、攻擊間隔
- 射程、投射物速度與傷害
- 生成機率
- 圖片與動畫
- `melee` 近戰行為
- `ranged` 遠程行為

目前尚未完全通用的部分：

- 衝刺後逃離
- 碰撞後持續扣血
- 太陽回血與曬黑值
- 分裂、召喚、改變地形等特殊行為

這些需要新增狀態效果或怪物狀態機。未來可建立通用狀態機，讓新增特殊怪物時主要修改設定檔即可。
